# Task Manager Project 
Консольное приложение для управления задачами.

## Стек технологий
- Java 21
- Maven
- PostgreSQL
- JDBC
- JUnit 5
- Mockito
- Git
- SLF4J + Logback

## Функционал
- Добавление задачи — описание проходит валидацию
- Удаление задачи по ID
- Изменение статуса задачи: PENDING / COMPLETED / ABANDONED
- Просмотр всех задач
- Фильтрация задач по статусу
- ID присваивается автоматически через PostgreSQL
- Хранение даты создания задач
- Автоматическое обновление статуса задач на ABANDONED

## Хранение данных
- Данные хранятся в PostgreSQL
- Работа с БД реализована с использованием JDBC
- Доступ к данным осуществляется через интерфейс Repository
- SQL-запросы написаны преимущественно через PreparedStatement
- ID задач генерируются БД

## Архитектура
Проект состоит из частей: UI, Repository, Model, Service, Commands
- Model - сущность проекта
- Repository - работа с БД
- Service - бизнес-логика приложения
- Commands - обработка действий пользователя при помощи паттерна Command
- UI - консольный ввод/вывод

## Исключения
- В проекте реализованы исключения RepositoryException и InputException
- RepositoryException - исключение, возникающие при работе с Repository
- InputException - исключение пользовательского ввода
- Исключения обрабатываются в слое UI, чтобы работа приложения не завершалась аварийно

## Тестирование
- В проекте для проверки слоя с бизнес-логикой реализованы unit-тесты на JUnit 5 и Mockito
- Тесты покрывают следующие операции:
  - успешное добавление задачи
  - проверку пустого описания
  - проверку невалидных символов
  - обрезку лишних пробелов в описании
  - удаление задачи
  - изменение статуса задачи
  - получение задач по статусу
  - взаимодействие TaskService с Repository
